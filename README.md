# Euler Problems in OCaml

Going through the Euler problems as listed [here](https://github.com/davidcorbin/euler-offline/blob/master/project_euler_problems.txt). Solutions are checked using the hashes provided in the same file.

AI tools have only been used to set up dune and the testing framework. All the code in `lib` has been written by the authors, with AI tools disabled.

## Quickstart

**To test**: `dune test`

**To format** `dune fmt`
